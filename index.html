Two CSS tools solve almost every layout problem. Flexbox arranges items along a single axis — ideal for navigation, button groups and centering. CSS Grid controls rows and columns at once — ideal for galleries, dashboards and full-page structure. Learn both by playing with them live.

Why Responsive Design Matters

More than half of all web traffic comes from mobile devices. A layout that only works on one screen size leaves most of your audience behind.

The old way

Early websites used fixed pixel widths and floated columns. They looked fine on the designer's monitor but broke on phones — text overflowed, columns collapsed, and users had to pinch and zoom just to read.

The modern way

Flexbox and Grid describe relationships between elements rather than fixed sizes. Combined with media queries, the same HTML reflows to fit any screen — no duplicate pages, no horizontal scrolling, no compromises.

Core Concepts

The four ideas that make a layout truly responsive.

⇄

Flexbox Layout

A one-dimensional model. Distribute space and align items along a row or column with justify-content and align-items.

▦

CSS Grid

A two-dimensional model. Define columns and rows explicitly, then place content precisely — perfect for galleries and page skeletons.

⤢

Media Queries

Apply different styles at different screen widths so spacing, font sizes and column counts adapt to the device.

📱

Mobile-First

Start with the smallest screen and progressively enhance for larger ones. It keeps CSS lean and forces you to prioritize content.

Flexbox vs CSS Grid — When to Use Which

They are partners, not rivals. Use Grid for the overall page structure and Flexbox for the content inside each area.

Reach for Flexbox when…

  • Aligning items in a single row or column
  • Building a navigation bar or button group
  • Centering something vertically and horizontally
  • Content size should decide the layout
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Reach for CSS Grid when…

  • Laying out rows and columns together
  • Building a card gallery or dashboard
  • You need overlapping or spanning areas
  • The layout should decide the content flow
.gallery {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
  gap: 1.5rem;
}

Frequently Asked Questions

Common questions about responsive layout.

Should I use Flexbox or Grid?

Use both. Grid is best for the two-dimensional page structure; Flexbox is best for aligning items within a single row or column. Most real layouts nest Flexbox inside Grid areas.

What does mobile-first actually mean?

You write your base CSS for the smallest screen first, then use min-width media queries to add complexity for larger screens. It keeps the mobile experience fast and the CSS simple.

How do I stop horizontal scrolling on mobile?

Use box-sizing: border-box, avoid fixed widths wider than the viewport, set max-width: 100% on images, and add overflow-x: hidden as a safety net.

Do I need a CSS framework for this?

No. This entire page uses only native HTML and CSS. Flexbox and Grid cover the layout needs that frameworks were originally built to solve.
